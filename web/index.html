        Estado de las fuentes

        Medios que no se pudieron leer en la última revisión. El resto de las noticias se muestra con normalidad.

        Un error de RSS no significa que el medio haya dejado de publicar. Las fuentes no se eliminan automáticamente.

        Acerca de Radar RSS

        Radar RSS reúne titulares, extractos breves y enlaces a noticias de medios y blogs externos. Cada artículo enlaza al sitio original y sus derechos siguen perteneciendo a sus respectivos autores.

        Las fuentes se organizan en ocho categorías, inicialmente importadas desde OPML. Los contenidos se recopilan mediante GitHub Actions y se publican de forma estática. La frecuencia programada es de aproximadamente tres horas, sujeta a disponibilidad de GitHub y de cada feed.

        Los artículos guardados y marcados como leídos se conservan solo en este navegador; no hay cuentas, sincronización entre dispositivos ni seguimiento personal desde esta aplicación. Las imágenes externas pueden realizar solicitudes a los sitios de sus editores.

        Un RSS con error o sin noticias recientes no implica necesariamente que el periódico haya cerrado. La revisión editorial es necesaria antes de retirar una fuente.
